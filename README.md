**Atoms** — 2D-симуляция идеального газа на Go с визуализацией через Ebiten. Частицы (атомы) летают в прямоугольном сосуде, упруго отскакивают от стенок, сталкиваются друг с другом. **Цель** — наблюдать эмерджентное поведение: распределение скоростей Максвелла, сохранение энергии, диффузию, тепловое равновесие.
